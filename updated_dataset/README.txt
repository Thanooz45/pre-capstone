Height-Weight Dataset (updated)

One row per person (22 people).
Columns: Sno, Name, Height (cm), Height (ft-in), Weight (kg), Camera Height from Ground (cm),
then image file names for each Distance from Camera (150 cm, 200 cm) x View (Front, Side).

Image naming: Name_150F.jpg, Name_150S.jpg, Name_200F.jpg, Name_200S.jpg
  (F = front view, S = side view). All images are in the images/ folder.
Camera Height from Ground = 100 cm for every person.
Height (ft-in) is formatted as feet and inches, e.g. 5'7''.
Blank image cells = no photo for that distance:
  only 150 cm: Balaji, Manoj
  only 200 cm: none
